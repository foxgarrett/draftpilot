Draft Pilot — Privacy Policy

Last updated: 2026-08-08

Draft Pilot is a browser extension that exports Sleeper Fantasy Football draft data to CSV and XLSX files, and computes league-specific analysis from your past drafts. This document describes exactly what data the extension touches, where that data lives, and what it never does.

Summary: Draft Pilot has no backend and no analytics. Everything it processes stays on your device or is a request to Sleeper's public read-only API. It doesn't collect personal information, track usage, or share anything with third parties beyond Sleeper's own API.

What data Draft Pilot stores on your device

The extension uses chrome.storage.local (or the Firefox equivalent), which lives entirely in your browser profile. No data leaves your device from this storage. Specifically, Draft Pilot saves:

  • Your Sleeper username — remembered so you don't have to re-enter it every time you open the popup.
  • Cached analysis of your past drafts — computed tier prices, rookie multipliers, and the list of your leagues. Refreshed when you click Sync League Data.
  • Timestamp and player count of your most recent exports — used only to show "Last export: N players (2h ago)" in the popup.

All of the above is removed automatically when you uninstall the extension, or manually via your browser's extension settings.

What data Draft Pilot transmits

Draft Pilot makes HTTPS requests to exactly one external service: Sleeper's public API at api.sleeper.app. All requests are read-only GET calls to public endpoints that require no authentication. Specifically:

  • GET /v1/user/{username} — resolve a public Sleeper username to a user ID
  • GET /v1/user/{id}/leagues/nfl/{season} — list a user's leagues per season
  • GET /v1/league/{id} and /league/{id}/users — read league settings and member display names
  • GET /v1/draft/{id} and /draft/{id}/picks — read draft settings and pick history

These requests contain only publicly available identifiers you already have in the URL of your Sleeper draft pages. Draft Pilot never sends your data anywhere else.

What data Draft Pilot reads from Sleeper draft pages

When you click Export Draft Room on a Sleeper draft URL (sleeper.com/draft/* or sleeper.app/draft/*), Draft Pilot's content script reads the player list rendered on that page — projections, positions, teams, byes, stats, ranks — and packages it into a CSV downloaded to your computer. That reading happens locally in your browser. Nothing is transmitted.

Files downloaded by Draft Pilot

All exports are written directly to your browser's default Downloads folder using a standard <a download> link. No cloud upload, no server-side processing. The files contain only the data you asked to export.

What Draft Pilot does not do

  • No analytics, telemetry, error reporting, or usage tracking of any kind
  • No advertising, ad IDs, or marketing pixels
  • No cookies set by the extension
  • No third-party servers contacted other than Sleeper's public API
  • No account creation or login collected by Draft Pilot itself
  • No personal data (email, phone, real name, payment info) — Draft Pilot never asks for any of it
  • No selling, sharing, or transferring of any data to anyone

Permissions the extension requests

  • storage — used only for the local cache described above.
  • host_permissions for sleeper.com/draft/*, sleeper.app/draft/*, and api.sleeper.app/* — used only to run the extension's content scripts on Sleeper draft pages and to call Sleeper's public API. No wildcard site access.

Your controls

  • Uninstall the extension to permanently remove everything Draft Pilot has stored locally.
  • Clear extension storage at any time via your browser's extensions page.
  • Re-sync at any time to replace the cached analysis with a fresh copy from Sleeper.

Children

Draft Pilot is not designed for or directed at children under 13. It collects no personal information about anyone, children or otherwise.

Changes to this policy

If Draft Pilot's data practices ever change, this document will be updated with a new Last updated date. Because the extension is open source, any code change that affects data handling is visible in the repository's commit history.
